# Вложенность и общее переподключение

Геометрическое вложение — отношение рисунков текущего представления, а не новое отношение ArchiMate. Полностью помещённый внутрь узел получает наименьший подходящий видимый контейнер. Подсветка показывает его до отпускания; выбранный контейнер не может стать собственным потомком. Перемещение группы сохраняет её дочерние рисунки. Выход за границы контейнера снимает геометрическую привязку; скрытый viewpoint родитель сохраняется, пока ребёнок остаётся внутри него. Новые невидимые родители не выбираются.

Создание из палитры, повторное использование концепта и перемещение используют отдельные настройки предложения отношения. По умолчанию предложение оставляет только геометрию. Пользователь явно выбирает направление и тип; показаны только ALLOWED результаты проверенного реестра для точных типов концов и текущего viewpoint. Настройки списка типов не превращают UNKNOWN в допустимость. Существующее точное отношение предлагается для использования; если его рисунок уже соединяет эти экземпляры, новая линия не создаётся. Отмена отменяет размещение целиком. Отказ от отношения применяет только геометрию. При отсутствии допустимых предложений или выключенной настройке применяется только геометрия. Всё действие записывается одним Undo.

Проверка типов концов не доказывает нормативный смысл представления отношения вложенностью. Этот отдельный смысл остаётся UNKNOWN, пока не появится соответствующая проверенная норма ArchiMate 4. Явное ручное создание UNKNOWN отношений с предупреждением остаётся самостоятельным сценарием редактора.

Скрытие линии при вложении меняет только отображение. Общий объект отношения, его рисунок, маршруты и якоря остаются в файле и навигации. При выходе из контейнера линия снова видна. Для каждого рисунка линии доступны прямой, ортогональный и скруглённый маршруты, переход на пересечениях и прозрачный, сплошной либо вырезающий линии фон подписи.

Команда **Модель → Переподключить общее отношение…** работает для выбранного общего отношения или его линии. Она перечисляет все рисунки, в том числе несколько в одном представлении. Для каждого пользователь выбирает точный экземпляр/якорь нового концепта либо явно создаёт новый экземпляр элемента/junction на месте прежнего конца. Для отношения-конца требуется существующий точный якорь. Автоматического выбора первого похожего рисунка нет. Предпросмотр проверяет весь кандидат, блокирует новые доказанные запреты, сохраняет маршруты/якоря/подписи и требует отдельного подтверждения. Одно Undo восстанавливает общее отношение и все рисунки.

Диалоги привязаны к документному token, экземпляру store, revision и активному представлению. Открытие и отмена не меняют модель; устаревший предпросмотр не применяется. Команды не меняют baseline сохранённого файла или Git.

Порядок палочки настраивается как «сначала концы» или «сначала тип отношения». Alt при включении временно меняет порядок, не записывает настройку и не отключает обычную проверку создания.

Focused core/DOM regression tests: `schemka-model-core/test/semantic-editing.test.js`, `schemka-model-ui/test/semantic-editing-ui.test.js`. Native Windows GUI и DPI 100/150/200 проверяются отдельно; эти тесты не являются такой приёмкой.
