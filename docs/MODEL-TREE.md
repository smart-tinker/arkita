# Дерево модели

В левой панели одно дерево. Постоянные разделы: Общие, Стратегия, Бизнес,
Приложения, Технологии, Мотивация, Реализация и миграция, Отношения и
Представления. Junction находятся в Общих. Раздел остаётся доступен и пустым.

Внутри раздела можно создавать вложенные папки через ПКМ. Стрелка раскрывает
ветвь, выбор имени выбирает объект; ПКМ открывает действия и свойства.
Пункт «Перейти внутрь» временно показывает содержимое папки с путём,
кнопками «Назад» и «К началу». Навигация не меняет модель и сбрасывается при
переключении модели; если текущая папка удалена или перенесена, дерево остаётся
в ближайшем существующем родительском контексте.
Перетаскивание объекта на полотно добавляет изображение того же объекта.
Перемещение между папками имеет предпросмотр и отменяется одним Undo.
Перенос в другой раздел не меняет семантический тип и блокируется.

Счётчики разделов и папок учитывают все объекты соответствующей ветви, включая
вложенные папки и следующие страницы. Просмотр дерева, сортировка, раскрытие,
поиск и переход к объекту не меняют модель. Для длинных списков сохраняются
страницы; переход из поиска раскрывает предков и нужную страницу.

## Существующие модели

ID объектов и папок, документация, свойства, исходные ID Archi, расположение
рисунков и отношения сохраняются. При открытии данные не перекладываются.
Одна старая папка с объектами разных разделов видна в нескольких ветвях:
каждая ветвь показывает только свои объекты. Это одна общая папка, не копии.
Переименование и удаление такой папки относятся ко всем её ветвям; удаление
папки сохраняет содержимое, что показано в подтверждении. Перенос общей папки
сразу между несколькими разделами блокируется; объекты можно переносить
по разделам отдельно.

Для пустой старой папки без сведений о разделе используется единственный раздел
родителя, если он известен; иначе — Общие. Исходная категория некоторых старых
папок Archi ранее не сохранялась, поэтому её нельзя надёжно восстановить по имени.

Новые папки сохраняют расположение пустой ветви в обычном свойстве
`arkita:catalog-section`: `common`, `strategy`, `business`, `application`,
`technology`, `motivation`, `implementation`, `relationships` или `views`.
Формат `.arkita` остаётся прежним (`schemka-project@4`); это не новый тип элемента.
Все остальные свойства сохраняются в прежнем порядке, включая повторные ключи.
При занятом служебном ключе или лимите 64 свойств перенос отклоняется с объяснением;
данные ради назначения раздела не удаляются.
