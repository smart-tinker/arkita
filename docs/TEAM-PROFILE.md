# Профиль команды и переносимый запуск

Arkita при запуске читает только `arkita-team-profile.json` рядом с `Arkita.exe`.
Для portable EXE это каталог исходного portable-файла, а не временная распаковка.
Файл необязателен; код, сетевые адреса загрузки и исполняемые расширения в нём
не поддерживаются. Лимит — 32 MiB, до 16 шаблонов. Некорректный профиль отклоняется
с сообщением в настройках; личные настройки и модели сохраняются.

Приоритет: встроенные значения → профиль команды → сохранённый личный профиль.
Личный профиль применяется целиком. Изменение командного файла начинает действовать
после перезапуска и не затирает личный профиль. «По умолчанию (черновик)» в настройках
позволяет явно принять актуальную базу команды; «Применить» сохраняет личный выбор.
Без личных настроек командная база не записывается как личное переопределение.
Цвета, шрифты и палитра — часть предпочтений. Шаблоны команды доступны только для
чтения, с отдельным источником: одинаковый ID локального шаблона не подменяет их.
Создание модели из шаблона выдаёт новые ID. Обновление профиля не открывает и не
преобразует существующие пользовательские модели.

Профиль собирает координатор команды. В «Вид → Настройки…» экспортируйте сохранённые
настройки в `Arkita-preferences.json`; нужные шаблоны экспортируйте через
«Файл → Шаблоны и доски…». Объединить их можно обычным PowerShell, без Node.js:

```powershell
$profile = [ordered]@{
  format = 'arkita-team-profile'
  version = 1
  id = 'team.architecture'
  name = 'Архитектура'
  revision = '2026-10'
  preferences = [IO.File]::ReadAllText((Join-Path $PWD 'Arkita-preferences.json'))
  templates = @(
    [IO.File]::ReadAllText((Join-Path $PWD 'Shared.arkita-template.json'))
  )
}
$json = $profile | ConvertTo-Json -Depth 4
$output = Join-Path $PWD 'arkita-team-profile.json'
$bytes = [Text.UTF8Encoding]::new($false).GetBytes($json)
$stream = [IO.File]::Open($output, [IO.FileMode]::CreateNew)
try { $stream.Write($bytes, 0, $bytes.Length) } finally { $stream.Dispose() }
```

Для профиля без шаблонов укажите `templates = @()`. Поля `preferences` и каждый
элемент `templates` — строки с исходными экспортированными JSON, а не вложенные
объекты. Чужие поля и версии отклоняются существующими строгими readers.
Кодек для разработчиков: `schemka-model-io/src/team-profile.js`.

Разместите проверенный файл рядом с нужным EXE. Для обновления сначала сохраните
предыдущую копию. Совместное использование личного профиля несколькими версиями
не преобразует модели на диске: старый формат открывается в памяти и требует
отдельного Save As. Неподдерживаемый формат личных настроек не перезаписывается
при чтении. Чистая установка и portable работают от обычного пользователя;
фактическая Windows-проверка привязана к конкретному дистрибутиву в отчёте выпуска.
