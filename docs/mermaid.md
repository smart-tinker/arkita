# Схемка

Небольшой локальный редактор Mermaid flowchart: связи мышью, подписи и удаление объектов, вложенные группы и исходный `.mmd` рядом с полотном.

**Один HTML-файл. Без сервера, аккаунта, подписки и сетевых запросов во время работы.**

English: an offline visual Mermaid flowchart editor with source-preserving edits.

## Начать

1. Скачайте HTML из раздела **Releases** этого репозитория или соберите его командой ниже
2. Откройте файл в настольном браузере
3. Откройте `.mmd` или вставьте код слева и дождитесь статуса «Схема обновлена»
4. Потяните кружок одного блока на другой, чтобы добавить связь
5. Сохраните результат кнопкой «Скачать .mmd»

ZIP релиза содержит тот же HTML, документацию и лицензии компонентов. Файл `SHA256SUMS` позволяет проверить скачанные файлы. Храните свои схемы отдельно: автосохранения документа нет.

## Что умеет

- Выделение блока, стрелки и группы; единое меню действий
- Изменение подписи без изменения ID
- Удаление стрелки с сохранением её конечных блоков
- Удаление блока вместе с его связями
- Перенос блока в существующую вложенную группу или наружу
- Разгруппировка с сохранением содержимого и его переносом в родительскую группу; связи непосредственно с удаляемой группой удаляются после подтверждения
- Сохранение назначения `linkStyle` после удаления связей
- Добавление блоков шести форм, pan/zoom, светлая/тёмная/системная тема
- Единый Undo/Redo для кода и визуальных изменений
- Импорт и экспорт `.mmd`; JSON-проект сохраняет исходник и вид полотна

`Ctrl/⌘ Z` — отмена, `Ctrl/⌘ Shift Z` или `Ctrl/⌘ Y` — повтор. `F2` открывает подпись, `Delete` — подтверждение удаления. Правый клик, `ContextMenu` или `Shift+F10` открывают действия; `Escape` закрывает панель. `Ctrl/⌘ Enter` обновляет схему.

## Как сохраняется исходник

Редактор изменяет только необходимые участки текста. Перед записью результата Mermaid повторно разбирает схему, а проверки сравнивают ID, подписи, формы, стили, связи и вложенность. Если результат неоднозначен или затрагивает что-то ещё, операция отклоняется целиком с пояснением.

В неизменённом UTF-8-файле сохраняются BOM и CRLF. Ручное редактирование в текстовом поле браузера может нормализовать окончания строк. Экспорт `.mmd` сохраняет текущий исходник, включая ещё не применённые правки.

## Ограничения

Это небольшой pet-проект и **не полный визуальный редактор всей грамматики Mermaid**.

- Визуальные операции работают с `flowchart`/`graph`
- Раскладку выполняет Dagre; свободного перетаскивания отдельных узлов нет
- Для некоторых действий требуется уникальное отдельное объявление блока
- Неоднозначные цепочки, параллельные связи, повторные объявления и некоторые современные/Markdown-подписи редактируются через текст
- Используется Mermaid Tiny 12.1.0: без ELK, mindmap, architecture и KaTeX. Запросы ELK и математические подписи `$$…$$` отклоняются явно, без скрытой замены раскладки
- Внешние ресурсы, переходы и `click`/callbacks отключены
- Техническая защита: 5 МиБ текста и 10 000 связей. Коммерческого лимита строк нет, но скорость больших схем зависит от браузера

**Реальная браузерная и визуальная QA для этого релиза не выполнена.** Автотесты проверяют исходник, официальный Mermaid-парсер, DOM и события с подставленной геометрией в jsdom. Они не подтверждают поведение нативного браузерного Undo, реальную раскладку, pointer capture или внешний вид. Начните с копии схемы.

## Разработка

Нужен Node.js 22 или новее. Зависимости нужны только для тестов; готовый HTML работает автономно.

```sh
npm ci --ignore-scripts
npm test
npm run build
```

Результат сборки: `dist/schemka.html`. Сборка использует только Node.js и проверенные локальные файлы, не скачивает зависимости и не запускает сервер. `package-lock.json` фиксирует тестовые зависимости.

Структура:

- `src/` — интерфейс, планировщики точечных правок и семантические проверки
- `vendor/` — зафиксированный Mermaid Tiny, адаптеры предварительной проверки YAML и инвентаризация лицензий
- `scripts/` — сборка, упаковка и проверка релиза
- `tests/` — проверки сборки, планировщиков, семантики и событий интерфейса

Исходники первого публичного релиза извлечены из сохранённого автономного HTML. Сборка воспроизводит его побайтно; тесты в этом репозитории восстановлены заново. Это не заявление о восстановлении прежних тестовых файлов.

## Версии и релизы

Версия приложения — в `package.json`, изменения — в [CHANGELOG.md](CHANGELOG.md). Для релиза:

```sh
npm ci --ignore-scripts
npm test
npm run release:pack
npm run release:check
```

Публикуйте тег `vX.Y.Z`, соответствующий проверенному коммиту, и три файла из `release/`: HTML, ZIP и `SHA256SUMS`. Не заменяйте файлы уже выпущенного релиза: исправления получают новую версию. Сборка побайтно воспроизводима. При одинаковой версии Node.js/zlib повторяется и ZIP: в нём фиксированы метки времени и порядок файлов.

## Governed viewpoints

Mermaid export rejects a selected view with `viewpointId`, even when its projection
is empty. Save the native project to retain the definition, binding and hidden
drawings. An unrelated unbound view keeps the existing export behavior. See
[VIEWPOINTS.md](VIEWPOINTS.md).
