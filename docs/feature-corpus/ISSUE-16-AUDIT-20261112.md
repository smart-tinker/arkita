Дата: 2026-11-12

Исходники: `main` `62aa1639752be2d4d345c97f4610e3673f0e5767`
CI того же SHA: [run 43201799027](https://github.com/smart-tinker/arkita/actions/runs/43201799027) — Ubuntu и Windows jobs успешны.

Здесь зафиксировано наличие кода и evidence, а не приёмка каждого критерия. Базовая сверка не запускала тесты повторно. Audit commits `54ed22b0bfe50ef2149789a1a2a079c1ab9bb5a0` и `d5e38b1f0047e7c0c4d0cfcd7a4144723ee83201` добавили focused regressions: multi-view rebind — UI 8/8 и core 7/7; route-relative labels — `connection-presentation` 8/8 и `visuals-ui` 16/16 (24/24). Последняя проверка подтверждает сохранение label anchor/offset через style dialog и project codec, Undo, и размещение подписи после изменения bendpoint и смены направления endpoints. ## Решение и следующий шаг

- В актуальном `main` уже есть существенная реализация вложенности и оформления связей, поэтому старые `Факт по коду` из базовых карточек не следует читать как текущую инвентаризацию. Текущие evidence и остатки закреплены в `program.json`.
- Остатки source/test: диагностика пары вложенных рисунков (`A-ADV-028`) и общая выбираемая стратегия ортогонального примыкания (`A-ADV-127`). Для `A-EXT-014` route-relative style, bendpoint edit и endpoint direction покрыты тестами; остаются native rendering/long-label handle и пользовательская инверсия. Для `A-ADV-132` source regression добавлен, остаётся native dialog acceptance. `A-ADV-126/128/129/130/131` имеют отдельные визуальные или export/print пробелы, не основание расширять код без подтверждённой потребности.
- Ветка `0.7.1-rc.1` остаётся только для согласованных Windows test/CI fixes. Новые editor features из этого аудита — отдельные задачи после RC, в `0.8.0-alpha.1`. Issue #16 остаётся открытым, пока нужные решения/регрессии и применимая Windows-приёмка не подтверждены.
- Multi-view rebind и route-relative label regression проверены focused suites на draft-ветке. Следующий шаг — native smoke rebind и label edit на представительной модели; GUI-инверсию отношения следует принимать отдельно от геометрической смены направления endpoints. Диагностика пары вложенных рисунков и общая ортогональная стратегия требуют подтверждённых контрактов. Максимальные capacity/стресс-сценарии не являются обязательной частью этого issue.
